# Demonstrações | Lorenzo Carvalho

Projetos de demonstração para apresentar a clientes como transformo uma ideia em uma experiência utilizável: sites, agentes de IA e análise de dados. Cada exemplo explica o objetivo, o que foi construído e como explorar o resultado.

## Projetos

| Área | Demonstração | O que você encontra |
| --- | --- | --- |
| Sites | [Páginas para diferentes negócios](sites/README.md) | Quatro exemplos de páginas em HTML: confeitaria, nutrição, pousada e salão. |
| Agentes de IA | [Jarvis pessoal](agentes-ia/jarvis/README.md) | Imagem e estudo de caso de um assistente com conversas, memória em notas e áreas de trabalho. |
| Análise de dados | [Vendas fictícias](analise-de-dados/vendas-demo/README.md) | Dados de exemplo, código reproduzível e perguntas de negócio respondidas. |

## Como navegar

Abra uma das demonstrações acima. Os projetos de sites estão no repositório [demonstrar](https://github.com/lorenzocarvalho588-creator/demonstrar); os demais materiais ficam aqui.

Os números da análise são fictícios. O Jarvis é um projeto pessoal: este repositório apresenta o produto e suas decisões, sem publicar conversas, credenciais ou informações privadas.
